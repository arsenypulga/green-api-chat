# Тестовое задание: Frontend React Developer (GREEN-API / MAX)

## Описание
Веб-интерфейс для отправки и получения текстовых сообщений через GREEN-API.

## Технологии
- React (Vite)
- CSS (Flexbox/Grid)
- Fetch API для работы с REST GREEN-API

## Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/arsenypulga/green-api-chat.git
   cd green-api-chat

2. Установите зависимости: 
   npm install

3. Запустите проект в режиме разработки:
   npm run dev

4. Откройте браузер по адресу http://localhost:5173
